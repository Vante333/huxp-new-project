# 新增升降级权益策略3 - 模块拆分

## 拆分概览

| 模块编号 | 模块名称 | 涉及接口/流程 | 功能点数 |
|---------|---------|-------------|---------|
| M1 | 升降级整体流程（策略3） | Change Membership Program API | 4 |
| M2 | 多等级权益映射 | 内部逻辑 | 2 |
| M3 | 权益模板匹配判断 | 内部逻辑 | 3 |
| M4 | 共享/充值权益迁移 | SAAS接口 | 3 |
| M5 | 持卡人/携伴专属权益迁移 | SAAS接口（批量） | 4 |

## M1: 升降级整体流程（策略3）

### 涉及接口
- Change Membership Program API（升降级接口，新增枚举值3）

### 核心功能点
1. 新增权益迁移策略X，枚举值为3
2. 该策略仅限指定租户（Revolut）可用
3. 步骤2（权益作废与重发）为本次变更重点，步骤1/3/4不变
4. 升降级4步流程：激活新等级 → 权益作废重发 → 清零旧等级权益 → 冻结旧等级

### 业务规则
1. 枚举值3仅指定租户（Revolut）可使用
2. 步骤1（激活新等级会籍/开卡）不变
3. 步骤3（清零旧等级权益明细）不变
4. 步骤4（冻结旧等级）不变

### 错误码
| 错误码 | 触发条件 | 错误信息 |
|-------|---------|---------|
| 500.030.029 | 存在异常权益（无限共享权益） | Abnormal entitlements detected. Operation cannot be performed. |

## M2: 多等级权益映射

### 涉及接口
- 内部逻辑（无独立接口）

### 核心功能点
1. 建立 Program A/B 不同等级权益的对应关系
2. 按 tier 级别对应迁移：tier1→tier1 的充实/大客户持卡人/大客户携伴/大客户共享

### 业务规则
1. 原 program 对应 tier 的权益组合，要整体对应迁移到新 program 中相同 tier 的组合
2. 权益类型包括：充实、大客户持卡人、大客户携伴、大客户共享

### 错误码
无独立错误码

## M3: 权益模板匹配判断

### 涉及接口
- 内部逻辑（权益模板查询）

### 核心功能点
1. 按权益类型检查目标 program 是否存在对应的权益模板
2. 所有权益类型都有对应模板时：迁移成功，直接调用SAAS接口发放权益明细
3. 任一权益类型缺少对应模板时：整个 tier 迁移失败

### 业务规则
1. Tier 1 场景：权益点-持卡人/携伴/共享 + 买点-共享 均存在模板 → 直接发放
2. Tier 2 场景：部分权益（携伴/共享）不存在模板 → 整体迁移失败
3. SWAP 权益模板判断：需匹配相同 swap 配置的模板
4. SWAP 配置不一致的模板视为"不存在权益模板"

### 错误码
无独立错误码（迁移失败的具体错误码未定义）

## M4: 共享/充值权益迁移

### 涉及接口
- SAAS 接口（发放权益明细）

### 核心功能点
1. 共享权益：按原 program 权益余额重发到目标 program
2. 充值权益（买点）：目标 program 没有权益明细则创建，已有则更新
3. 异常检测：目标与原等级都不应存在无限的共享权益

### 业务规则
1. "有多少点就迁移多少点"——按实际余额迁移
2. 充值权益定义：权益类型为"充值"的权益明细
3. 共享权益定义：权益类型为"大客户"，且打开了"权益是否共享"的权益明细
4. 若存在无限共享权益，返回错误码 500.030.029

### 错误码
| 错误码 | 触发条件 | 错误信息 |
|-------|---------|---------|
| 500.030.029 | 目标或原等级存在无限的共享权益 | Abnormal entitlements detected. Operation cannot be performed. |

## M5: 持卡人/携伴专属权益迁移

### 涉及接口
- SAAS 接口（批量操作）

### 核心功能点
1. 场景A：无限点(-1) → 有限点(模板配置) = 迁移后为 0
2. 场景B：无限点(-1) → 无限点(-1) = 迁移后为 -1
3. 场景C：有限点(N) → 无限点(-1) = 迁移后为 -1
4. 场景D：有限点(N) → 有限点(模板配置M, M≥N) = 迁移后为 N（保留原余额）

### 业务规则
1. 无限→有限：权益清零（归0）
2. 任意→无限：权益变为无限(-1)
3. 有限→有限：保留原有余额
4. 支持批量操作

### 错误码
无独立错误码
