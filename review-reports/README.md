# 评审报告目录

存放**需求评审、技术方案评审**等过程拆解与结论的 Markdown（如模块拆分、关系分析、评审报告定稿）。

- **命名建议**：与 Jira 工单或主题一致（如 `PAPI-xxxx-01-模块拆分.md`、`xxx-评审报告.md`），便于与 [`requirements/`](../requirements/)、[`tech-docs/`](../tech-docs/) 对照。
- **与业务文档关系**：评审稿可引用需求/技术文档路径；定稿结论若需长期维护，请同步更新对应 `requirements/` 或 `tech-docs/` 正文，避免仅在本目录留孤本。
