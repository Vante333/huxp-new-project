# api-automation 目录说明

本目录用于存放与本专题相关的**接口自动化**资料，例如：

- Apifox / Postman 等工具导出的接口集合文件（如：`entitlements-collection.json`）。
- 接口自动化用例覆盖说明文档（如：`entitlements-auto-test-cases.md`），描述自动化脚本覆盖的接口、场景及依赖。
- 运行说明（环境变量、鉴权方式、执行命令等）。

建议：
- 将正式使用的接口自动化集合文件统一放在本目录，便于与需求、测试用例分层管理。
- 在 README 中补充团队约定的环境（dev / test / prod）及变量命名约定。
