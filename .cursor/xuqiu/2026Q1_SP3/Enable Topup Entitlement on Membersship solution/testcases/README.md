# testcases 目录说明

本目录用于存放当前专题（Enable Topup Entitlement on Membership solution）的**功能测试用例**文档。

- 测试用例文件命名建议：`Enable-Topup-Entitlement-测试用例-01.md`、`Enable-Topup-Entitlement-测试用例-02.md` 等。
- 编写规范请参考 `.cursor/rules/test-case-design-rules.mdc` 中的《功能测试用例规范指南》。
- 用 Markdown 的 H1～H6 分层结构组织模块、测试点、验证点、用例场景和预期结果，保证可导入 XMind 等工具。
