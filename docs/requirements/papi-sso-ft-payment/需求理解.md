## 需求一：SSO 免登短链（H5 SSO API 一期）

**要做什么：**  
调用接口生成一个**短时免登链接**，打开后可直接进入指定 H5 场景（免再登）。

**接口：** `POST /api/v2/sso/links`

**请求要点（你需要懂的）：**
| 字段 | 是否必填 | 含义 |
|------|----------|------|
| `subject.type` / `subject.id` | 选填 | 入口身份：MEMBERSHIP / EPASS / CLIENT_USER；不传则游客模式 |
| `scene` | 必填 | 进哪个场景 |
| `language` | 选填 | 默认 `en-US` |
| `durationInSeconds` | 选填 | 默认 60，范围 60～7200 |
| `returnUrl` | 选填 | 回跳地址，默认空 |
| `extra` | 看场景 | 场景附加参数 |

**本期场景：**
| scene | 含义 | extra |
|-------|------|-------|
| `ORDER_LIST` | 订单列表 | 不需要 |
| `ORDER_DETAIL` | 订单详情 | **必须有 `orderId`** |

**返回你要关心的：**
- `entry.shortUrl`：免登短链（如 `https://dp8.co/AbC123`）
- `entry.validUntil`：链接过期时间戳

**缺 extra 必填时错误：** `500.000.602`（提示 extra.{字段} 在该 scene 下必填）

## 需求二：FT 可用性过滤已过时间段

**要做什么：**  
查 Fast Track 可预约时段时，**把已经过去的时间过滤掉**，避免还能生成 token、到下单才失败。

**判断依据：** 接口给的时间 + 资源时区 → 是否早于当前当地时间。

**新错误：**
- 码：`500.020.030`
- 中文：预约时间早于当前时间
- 英文：The prebooking time cannot be earlier than the current local time.

**同时：一堆旧错误码要改号（迁移）：**
| 旧码 | 新码 |
|------|------|
| 500.020.030 | 500.030.039 |
| 500.020.031 | 500.030.040 |
| 500.020.032 | 500.030.041 |
| 500.020.033 | 500.030.042 |
| 500.020.034 | 500.030.043 |
| 500.020.035 | 500.030.044 |

注意：表里「旧 500.020.030 → 新 500.030.039」，同时又新增「预约过期」也叫 `500.020.030`，测试时要和开发确认：**最终线上到底哪个含义占用 500.020.030**，避免断言冲突。

**另：** `memberships/purchase/details` 增加错误码 `500.030.045`  
文案：Sorry, we're unable to retrieve the order details...

## 需求三：创建支付链接支持语种 + 有效期

**要做什么：**  
创建支付链接时，可指定**支付页语种**和**链接有效时长**。

**接口：** `/v2/orders/payments`（文档：Apifox 6000066）

**新增入参（对外）：**
| 字段 | 必填 | 默认 | 说明 |
|------|------|------|------|
| `language` | 否 | `en-US` | 支付页语种 |
| `durationInSeconds` | 否 | 1800 | 有效秒数；**最长 1800** |

**往 SaaS 映射（实现侧）：**
- `language` → `lg`（不转换，直接传如 `en-US`）
- `durationInSeconds` → `expireIn`

**示例：**
```json
{
  "orderId": "DP00000000000001",
  "returnUrl": "https://example.com/payment/return",
  "paymentMethod": "H5_CASHIER",
  "language": "en-US",
  "durationInSeconds": 60
}
```

## 三者关系（帮你分清）

| 需求 | 解决什么 |
|------|----------|
| SSO links | 生成**免登进 H5** 的短链 |
| FT 过滤时段 | 预约**不能选/不能用过去的时间** |
| 支付 links | 支付短链的**语种**和**多久失效** |

都和「链接/时间」有关，但是**三个不同接口、三套规则**。
