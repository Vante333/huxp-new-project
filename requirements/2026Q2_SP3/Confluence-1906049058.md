## 一、概述

### 1.1 支持品类

一期：Lounge PB + FT

二期：其他（待定）

### 1.2 主要改动内容

商品选择部分：将原支持的【项目支付】+【现金支付】进行定义改造，支持按api参数进行动态选择，并在现金支付的前提下，额外支持权益抵扣（含第三方）；

订单流链路部分：将分为"计算价格"、"创建订单"、"订单确认与支付"、"订单分发"、"订单履约"五大块；

| 模块 | 改动 |
| --- | --- |
| 计算价格 | 改为调用saas接口计算价格；新增金额部分数据返回 |
| 创建订单 | 根据入参动态选择商品；金额部分信息基于saas计算好的数值去下单，不再需要自己计算 |
| 订单确认与支付 | 根据支付类型决定是否要调用saas接口拉起收银台；不再需要由api侧来更新支付相关数据，改为由saas监听pci的消息 |
| 订单分发 | 基本没变 |
| 订单履约 | 基本没变 |

### 1.3 参考资料

saas的需求：

支持第三方权益支付+现金支付流程

现金支付+权益支付（DP权益+第三方权益） 

saas的技术方案：

订单流（现金+第三方权益） 

新订单流对接

总结：

| 商品类型 | DP收款 | 客户收款 | 纯权益支付 |
| --- | --- | --- | --- |
| E-pass | ✅ DP_COLLECT + toUseUsageCount | ❌ 不支持 | ✅ 原逻辑 |
| Membership | ✅ DP_COLLECT + cashPaymentApplied=false | ✅ CLIENT_COLLECT + cashPaymentApplied=true | ✅ cashPaymentApplied=false |

| 参数 | 适用范围 | 说明 |
| --- | --- | --- |
| cashPaymentApplied | Membership/E-pass | 是否存在现金支付部分。false = 全权益支付或DP收款模式。true = 存在客户自行收款部分。 |
| toUseUsageCount | E-pass | 本次订单计划使用的 Usage 数量，仅用于 E-pass 的权益抵扣场景。 |
| toUseEntitlementCount | Membership | 本次订单计划使用的权益数量，仅用于 Membership 的权益抵扣场景。 |
| cashier.paymentMode=DP_COLLECT | E-pass / Membership | DP负责向用户收款 |
| cashier.paymentMode=CLIENT_COLLECT | Membership | 客户已向用户收费，DP不收款，仅记录和扣减权益。 |
| 不传 cashier | E-pass / Membership | 表示无现金支付流程。 |

### 2.2 预览订单接口

预览订单这步，saas不会检验会籍状态和权益点数，api侧需要保留权益与会籍状态检验，分别调用：

- saas权益计算接口-获取权益使用明细


- saas算价接口-获取payment object


### 2.2.1 payment object 返回内容
```json
"payment": {
                "currency": "USD",
                "price": {
                    "originalAmount": 120, //originalTotalAmount
                    "discountAmount": 40, //equityDiscountFee
                    "payableAmount": 80 //totalAmount
                },
                "breakdown": [
                    {
                        "type": "BASE_PRICE",
                        "details": [
                            {
                                "paxType": 1, //代表是CARDHOLDER or GUEST
                                "quantity": 1, //数量，
                                "unitPrice": 50, //单价，取overNumFee
                                "amount": 50 //总价
                            },
                            {
                                "paxType": 2,
                                "quantity": 1,
                                "unitPrice": 50, //单价，取overNumFee
                                "amount": 50
                            }
                        ]
                    },
                    {
                        "type": "PREBOOKING_FEE", //预约服务费
                        "details": [
                            {
                                "paxType": 1,
                                "quantity": 1,
                                "unitPrice": 10, //prebookFee除订单总人数
                                "amount": 10
                            },
                            {
                                "paxType": 2,
                                "quantity": 1,
                                "unitPrice": 10, //prebookFee除订单总人数
                                "amount": 10
                            }
                        ]
                    },
                    {
                        "type": "ENTITLEMENT_DEDUCTION",
                        "appliedTo": [
                            "BASE_PRICE"
                        ], //可以抵扣基础价格
                        "details": [
                            {
                                "paxType": 1,
                                "quantity": 1,
                                "unitPrice": -20, //就是我们是要写负数，0不用，equityDeductionUnitPrice
                                "amount": -20 //就是我们是要写负数，0不用，ownerDeductionAmount
                            },
                            {
                                "paxType": 2,
                                "quantity": 1,

                ]
            }
```

type和appliedTo的枚举枚举

| 枚举 | 描述 |
| --- | --- |
| BASE_PRICE | 超人次价格 |
| PREBOOKING_FEE | 预约服务 |
| SERVICE_FEE | 预留的其他服务费 |
| ENTITLEMENT_DEDUCTION（只有type有） | 权益抵扣多少 |
