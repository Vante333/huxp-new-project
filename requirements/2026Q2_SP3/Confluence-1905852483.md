## 一、E-pass注册+查询场景以注册量进行分级，重点在注册及查询接口

### 1.1 分级指标等级

| 等级 | 日注册量（以前7日均值统计） | 客户 |
| --- | --- | --- |
| Tier 1（核心） | ≥500/day | Gulfstream、MAYA Bank、SAILY、TravelMart |
| Tier 2（标准） | 50~499/day | GreyWall、GET YOUR GUIDE、Wise、Itaú、N26、VivoFacil、LoungePair |
| Tier 3（长尾） | <50/day | Grandoria、Make my trip、EPSILON、Tripadd、LoungePair B2B、Lyntel |

### 1.2 涉及接口

```text
https://developer-sandbox.dragonpass.com/api/v2/orders/{module}/ePasses
https://developer-sandbox.dragonpass.com/api/v2/orders/ePasses/search
https://developer-sandbox.dragonpass.com/api/v2/orders
```

### 1.3 全局监控指标

| 指标 | 阈值 |
| --- | --- |
| 全局注册成功率 | <99% |
| 全局5xx | >2% |

### 1.4 Tier 1指标

| 指标 | 告警值 |
| --- | --- |
| 告警窗口 | 5分钟 |
| 成功率SLO | 小于99.5% |
| 失败次数 | 5分钟 ≥ 10次 |
| Latency | P99 > 2s |
| 无流量 | 10分钟无请求 |
| 告警级别 | P1 |

### 1.5 Tier 2指标

| 指标 | 建议 |
| --- | --- |
| 告警窗口 | 10分钟 |
| 成功率SLO | 小于99% |
| 失败次数 | 10分钟 ≥10次 |
| Latency | P99 > 2s |
| 告警级别 | P2 |

### 1.6 Tier 3指标

| 指标 | 建议 |
| --- | --- |
| 成功率SLO | - |
| 告警窗口 | 1小时 |
| 失败次数 | 1小时 ≥5次 |
| 告警级别 | P3 |

## 二、E-pass 资源查询+订单相关场景以使用量进行客户分级，重点在资源+订单相关接口

### 2.1 分级指标

- 预订单利润大概是 walkin 的 3 倍
- 链路与客户要求更复杂，更高用户价值，也是重点发展业务
- walkin 业务较简单

评分公式：walkin前7日日均使用量x1+预订单前7日日均使用量x5

| 等级 | 按加权评分来 | 客户 |
| --- | --- | --- |
| Tier 1（核心） | score ≥ 500 | Gulfstream、TravelMart |
| Tier 2（标准） | 100 <= score < 500 | GET YOUR GUIDE、GreyWall、Wise、MAYA Bank |
| Tier 3（长尾） | score < 100 | 其他 |

### 2.2 涉及接口

资源类：

```text
https://developer-sandbox.dragonpass.com/api/v2/resources
https://developer-sandbox.dragonpass.com/api/v2/resources/{resourceId}
https://developer-sandbox.dragonpass.com/api/v2/resources/prebookings/availability
https://developer-sandbox.dragonpass.com/api/v2/search
```

订单查询类：

```text
https://developer-sandbox.dragonpass.com/api/v2/orders/ePasses
https://developer-sandbox.dragonpass.com/api/v2/orders/ePasses/details
```

订单创建+取消类：

```text
https://developer-sandbox.dragonpass.com/api/v2/orders
https://developer-sandbox.dragonpass.com/api/v2/orders/{module}/ePasses/prebooking
https://developer-sandbox.dragonpass.com/api/v2/orders/{module}/ePasses/bundle
```
