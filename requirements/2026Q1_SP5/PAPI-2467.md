# 预览订单、创建订单、订单详情新增usedEntitlementBreakdown array

**JIRA**: [PAPI-2467](https://dragonpass.atlassian.net/browse/PAPI-2467)

---

在下新增**usedEntitlementBreakdown** Array，展示详细扣点明细

- tier 字段，仅限FT/Lounge/Setmeal接口有，若没有使用tier权益则不返回该字段

- sourceType，基于权益类型判断，如果是单品了权益则是module_exclusive

- 扣了什么点，就展示什么object，没扣的不需要，例如没扣swap的，就不需要展示cross_module

- 一般情况下，单品类不会扣除2个tier的权益（除非配错），如果是，则展示2条。如果扣除的是同一品类同一tier的不同权益，例如都是休息室t1的持卡人点+共享点+买点共计3条明细，需要合并到一个object里

- 一般情况下，一个项目里只会有1个跨品类权益配置，如果配置了多种，如134+13，又刚好扣了2个1，需要合并显示。即最多只会展示1个"sourceType": "cross_module"

```
"usedEntitlementBreakdown": [
                {
                    "sourceType": "module_exclusive",
                    "tier": 1,
                    "entitlements": {
                        "cardholderExclusiveEntitlements": 1,
                        "guestsExclusiveEntitlements": 0,
                        "sharedEntitlements": 0,
                        "purchasedEntitlements": 0
                    }
                },
                {
                    "sourceType": "cross_module",
                    "entitlements": {
                        "cardholderExclusiveEntitlements": 1,
                        "guestsExclusiveEntitlements": 0,
                        "sharedEntitlements": 0,
                        "purchasedEntitlements": 0
                    }
                }
            ],
```
