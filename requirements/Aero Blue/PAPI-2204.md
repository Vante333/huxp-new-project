# 【Migration】Lounge/FT membership prebooking 相关接口新增内部字段 【V2】

**JIRA**: [PAPI-2204](https://dragonpass.atlassian.net/browse/PAPI-2204)

---

### 一、下单接口

针对休息室和FT预订单

[**https://developer-sandbox.dragonpass.com/api/v2/orders/fastTrack/memberships/prebooking**](https://developer-sandbox.dragonpass.com/api/v2/orders/fastTrack/memberships/prebooking)

[**https://developer-sandbox.dragonpass.com/api/v2/orders/lounges/memberships/prebooking**](https://developer-sandbox.dragonpass.com/api/v2/orders/lounges/memberships/prebooking)

extra中新增一个object** _internal，**包含三个字段，注意是带下划线的

Nacos中需要新增配置，只有配置了对应租户id才能传这个额外的object，否则统一兜底错误

订单创建时这些字段不做校验，有就有，没有就没有，仅作为记录存在

**没有配置的租户，整个object都不返回，配置了，没有值就返回null**

| **字段** | **放到saas ord.order feature下的json** |
|------|------|
| _amount | "revolut": {         "amount": "3.50",         "currency": "USD",         "exchangeRate": "0.823"     } |
| _currency |  |
| _exchangeRate |  |

```
"extra": {
    "_internal": {
        "_amount": "3.50",
        "_currency": "USD",
        "_exchangeRate": "0.823"
    }
}
```
