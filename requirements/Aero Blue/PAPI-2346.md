# PAPI-2346 【Aero Blue】价格查询接口新增字段支持获取用户价

来源：Jira <https://dragonpass.atlassian.net/browse/PAPI-2346>

> 说明：未发现可用 Confluence `/pages/<id>/` 链接；以下由 **Jira 描述** 导出。

---

![](images/image-20260423-060057.png)

---

影响以下接口：

`GET /v2/resources/fitness/{resourceId}/schedule?expand=price`

`POST /v2/resources/prices`

`POST /api/v2/resources/options/prices`

BOSS返回

```json
"priceList": [
                {
                    "bookPrice": 95.0,
                    "bookPricePayer": "entitlementToB_PAYGToC",
                    "bookPriceType": "ByPersonTime",
                    "maxPrice": 0.0,
                    "overNumPrice": 99.0,
                    "overNumPricePayer": "user",
                    "overNumPriceType": "fixedPrice",
                    "price": 93.0,
                    "priceDimensional": "DPC000059",
                    "priceType": "fixedPrice",
                    "userBookPrice": 98.0
                }
            ]
```

相关接口的返回中，pricing object格式调整，新增字段，

```json
{
    "code": 0,
    "data": {
        "pagination": {
            "pageSize": 10,
            "pageNumber": 1,
            "totalNumber": 1
        },
        "resources": [
            {
                "resourceId": "N00001",
                "resourceName": "Manchester Airport Lounge",
                "currency": "USD",
                "lastUpdatedTime": "2025-05-01T10:00:00+00:00",
                "pricingMode": 1, //计价模式
                "pricing": {
                    // ====== Legacy (兼容用) ======
                    "basePrice": 50.0, //不变
                    "prebookingFee": 5.0, //不变
                    // ====== New pricing model ======
                    "priceDetails": {
                        "basePrice": {
                            "settlement": 50.0,
                            "selling": 55.0
                        },
                        "prebookingFee": {
                            "chargingRule": "MIXED", //有3个，用户支付，客户支付，混合
                            "settlement": 5.0,
                            "selling": 5.0
                        }
                    }
                }
            }
        ]
    }
}
```

对应取值逻辑调整见下

没有值就返回null，不返回0
