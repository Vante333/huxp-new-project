# Membership Tier upgrade/down grade API ｜会籍升降级【V2】

**JIRA**: [PAPI-1107](https://dragonpass.atlassian.net/browse/PAPI-1107)

---

```
/v2/memberships/programChange
```

### 1. 背景

当前国际API项目有升降级的业务需要，主要体现为某个会员（customerUserId），在多个个会籍模板（program）间来回切换会籍。

升降级业务规则如下：

- 只允许进行升降级，未启用/冻结的会籍不允许发起迁移

- 有状态为启用中的会籍才

- 如果要迁移，当前等级和目标等级（会籍模板/program）中，各自仅允许存在一张启用/冻结中的会籍，如果某个program下有多个有效会籍，则不允许迁移**（现在也不会出现这种场景，本身api就不允许注册多个有效会籍）**。取消/注销不视为有效会籍，目标等级中如果有未启用的会籍，也不允许迁移

- 升降级机制：
    - 当会员进行升/降级操作后，需将原有会籍设置为冻结状态；（原有会籍权益不动）
    - 新的等级如果没有有效会籍，则创建新会籍
    - 新等等级如果原来已经有会籍，现在会冻结状态，则设为激活（再启用）

迁移操作需要支持以下两部分策略：

权益控制

- 可以重发权益，或不重发权益，或增发新会籍模板的权益

有效期控制

- 升降级后，会籍有效期不变

### 2. 入参

```
{
    "membershipId": "8888888800000000",
    "programId": "aaa",
    "targetProgramId": "bbb",
    "entitlementOptions": {
        "strategy": 1
    }
  "validityOptions": {
        "strategy": 1
    }

```

`membershipId`: dpid

`programId`: 当前的program，要验证上面的id是否是这个program

`targetProgramId`: 目标program，要验证token是否有权限操作这个program （同一个权限组）

`entitlementOptions.strategy`:

1, 清空新等级中会籍的旧权益，按新模板重新发放权益（只能发放新模板中有的品类权益）

2, 重开新等级中的旧卡，权益不变（仅在有旧卡的场景下支持）

一、先判断2个等级间，是否都只有1张有效会籍，可以再去判断二

`validityOptions.strategy`:

原来 20250101-20251231。今天20251127发生了迁移。

- 原来没卡，那就要新开卡
    - 固定日期型，需要20251127大于等于会籍模板的左区间，就是会籍模板有效期至少是从20251127开始的。若满足，新卡的有效期就是20251127-20251231，不满足就不允许。
    - 固定时长型，直接开，有效期就是20251127-20251231
    - 固定月日型，直接开，有效期就是20251127-20251231

- 原来有卡，只需要重新启用，那就只更新有效期结束时间20251231，有效期开始时间不变。

### 3. 影响范围

**预订单**

预订单是跟随会籍的，原来在哪个会籍创建，预订单就一直在那个会籍上，跟迁移业务无关。

迁移后，原会籍会变为冻结，如果这时取消了预订单，权益只会回退到原冻结的会籍中，不到新等级在用的会籍中。

**加减点**

api层，冻结状态的会籍是不能加点的

**迁移后再进行update**

不受影响，正常业务
