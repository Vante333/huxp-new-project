# /ePasses/details判断到MS订单给提示语【V1+V2】

**JIRA**: [PAPI-2424](https://dragonpass.atlassian.net/browse/PAPI-2424)

---

[**https://developer-sandbox.dragonpass.com/api/v2/orders/ePasses/details**](https://developer-sandbox.dragonpass.com/api/v2/orders/ePasses/details)

这个usage orderdetails接口，经常有客户把E-pass的MS订单号传进来，然后查不到东西来问。

新增一个判断逻辑，如果入参的订单号是MS开头，则返回提示语，引导他们去用search接口

| 500.000.024 | 查询了MS订单号 | The order ID you entered is not a usage order ID. If you want to query E-pass details, please use the /orders/ePasses/search API. |
