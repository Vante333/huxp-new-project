# 【Aero Blue】 membership注册接口，新增内部字段，用于接收项目非标信息｜Added internal field for receiving non-standard project information on membership registration and query API

**JIRA**: [PAPI-2548](https://dragonpass.atlassian.net/browse/PAPI-2548)

---

### 概述

新增内部字段用于接收项目非标信息，更新会员注册接口。

### 背景

在会籍注册接口 `/v2/memberships` 中，新增 `extensions` 数组以支持项目侧定制传入的 JSON 数据。该接口仅限内部租户使用。

### 验收标准

- 新增 `extensions` 数组，包含以下字段：
    - `type`: 字符串，内容不限制，长度 128
    - `value`: 字符串，内容不限制，长度 128

- 该接口放入 SaaS 会籍的 feature 字段，以后可能改为对 SaaS 真实字段。

- **「不做重复性判断」含义**：不做跨会籍、跨项目对 `value` 的全局去重或业务含义校验；**同一 membership 内 `type` 必须唯一**（见下方错误码 `500.030.032`）。

- `type` 在同一个 membership 下必须唯一（例如不能传入两条 `cardId`）。

- 最多支持 5 个 `type`（见错误码 `500.030.033`）。

- 暂时仅限内部租户使用，UAT Program ID 为 **0426**；**非内部租户**在注册/查询等接口响应中**不返回** `extensions` 数组（或等价于不可见）。

- **空态展示**：未传入或无数据时，`extensions` 展示为 **`[]`**（空数组）。

### 需求

#### 1. 会籍注册接口 `POST /v2/memberships` — 新增请求与对应返回

```json
"extensions": [
    {
        "type": "ailasId",
        "value": "123456"
    },
    {
        "type": "cardId",
        "value": "123456"
    }
]
```

#### 2. 会员查询接口 — 支持查询到上述信息

`POST /v2/memberships/search`

- 同样仅限内部租户（UAT 0426）；非内部租户不返回该数组。

#### 3. 会籍 extensions 更新接口 — 仅用于更新 `extensions`

**`POST /v2/memberships/extensions`**（以 OpenAPI / 网关发布为准；个别环境历史上曾使用 `PATCH` 同路径，联调时以实际网关文档为准。）

请求示例：

```json
{
  "membershipId": "8888000066668888",
  "extensions": [
    {
      "operation": "UPSERT",
      "type": "ailasId",
      "value": "123456"
    },
    {
      "operation": "DELETE",
      "type": "cardId"
    }
  ]
}
```

返回示例（**更新后的全部** `extensions`）：

```json
{
  "membershipId": "8888000066668888",
  "extensions": [
    {
      "type": "ailasId",
      "value": "123456"
    },
    {
      "type": "cardId"
    }
  ]
}
```

说明：

- `membershipId` 须存在且可访问，否则按契约返回失败。
- `operation` 仅支持 `UPSERT` 与 `DELETE`。
- `UPSERT`：有则更新 `value`，无则新增该 `type`。
- `DELETE`：不传 `value`；若 `type` 不存在则**不报错**（视为 noop）。
- 同一请求内可同时包含多条 `UPSERT` 与 `DELETE`。
- 无数据时响应中 `extensions` 为 **`[]`**。

### 错误码与响应 `msg`（根节点，英文）

失败响应中通常包含 **`errCode`**（字符串）与 **`msg`**（英文说明）。下表为约定全文（断言与联调时按**完全相等**或**包含整句**校验，具体以 OpenAPI 为准）。

| errCode | 场景 | 根节点 `msg`（英文全文） |
| --- | --- | --- |
| `500.030.032` | 同一会籍下 `extensions` 出现重复 `type` | `Duplicate extension type detected. Each type must be unique within a membership.` |
| `500.030.033` | 超过「最多 5 个 type」上限 | `A maximum of 5 extension types is allowed per membership.` |
| `500.030.034` | `POST`/`PATCH` `/v2/memberships/extensions` 更新失败（兜底） | `Failed to update membership extensions. Please try again later.` |

> 说明：若沙箱/历史版本曾使用**相邻编号**表示同类场景（例如旧实现将「重复 type」标为 `500.030.033`），自动化与联调以**实际响应 `errCode` + `msg`**为准，并与 OpenAPI 对齐；文案以上表为准。
