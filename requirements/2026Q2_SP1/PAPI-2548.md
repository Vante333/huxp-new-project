# 【Aero Blue】 membership注册接口，新增内部字段，用于接收项目非标信息｜Added internal field for receiving non-standard project information on membership registration and query API

**JIRA**: [PAPI-2548](https://dragonpass.atlassian.net/browse/PAPI-2548)

---

### 概述

新增内部字段用于接收项目非标信息，更新会员注册接口。

### 背景

在会籍注册接口 `/v2/memberships` 中，新增 `extensions` 数组以支持项目侧定制传入的 JSON 数据。该接口仅限内部租户使用。

### 验收标准

- 新增 `extensions` 数组，包含以下字段：
    - `type`: 字符串，内容不限制，长度128
    - `value`: 字符串，内容不限制，长度128

- 该接口放入 SaaS 会籍的 feature 字段，以后可能改为对saas真实字段

- 暂时不做重复性判断。

- type 在同一个 membership 下必须唯一，就是说不能传入2个cardId

- 最多支持5个type

- 暂时仅限内部租户使用，UAT ID 为 0426，其他组户接口不返回这个array

- 传入时没值展示[]

### 需求

1. 会籍注册接口 `/v2/memberships`新增请求与对应返回

```
"extensions": [
    {
        "type": "ailasId",// 不限制内容，长度128
        "value": "123456"// 不限制内容，长度128
    },
    {
        "type": "cardId",// 不限制内容，长度128
        "value": "123456"// 不限制内容，长度128
    }
]
```

2. 会员查询接口，支持查询到上述信息

- 暂时仅限内部租户使用，UAT ID 为 0426，其他组户接口不返回这个array

`/v2/memberships/search`

3. 新增更新接口，只用于更新 extensions

POST /v2/memberships/extensions

```
"membershipId": "8888000066668888",
"extensions": [
    {
        "operation":"UPSERT",
        "type": "ailasId",// 不限制内容，长度128
        "value": "123456"// 不限制内容，长度128
    },
    {
        "operation":"DELETE",
        "type": "cardId"// 不限制内容，长度128
    }
]
```

返回：

```
"membershipId": "8888000066668888",
"extensions": [
    {
        "type": "ailasId",// 不限制内容，长度128
        "value": "123456"// 不限制内容，长度128
    },
    {
        "type": "cardId"// 不限制内容，长度128
    }
]更新后的全部extensions
```

- membershipid要存在

- operation只支持UPSERT和DELETE

- UPSERT就是新增和更新，若有就更新，没有就新增

- DELETE就是删除，不需要传value，传错的type找不到也不用报错，就当是不执行删除

- 可以同时update和delete

- 传入时没值展示[]

| 500.030.032 | 重复type | Duplicate extension type detected. Each type must be unique within a membership. |
|------|------|------|
| 500.030.033 | 最多支持5个type | A maximum of 5 extension types is allowed per membership. |
| 500.030.034 | extensions更新失败兜底 | Failed to update membership extensions. Please try again later. |
