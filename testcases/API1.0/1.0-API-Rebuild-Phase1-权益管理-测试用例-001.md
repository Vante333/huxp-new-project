## 需求追溯

- **需求文档**：`requirements/API 1.0/API Rebuild Phase 1.md`（与 Confluence [1.0 API Rebuild Phase 1](https://dragonpass.atlassian.net/wiki/spaces/DGSN/pages/1670054171/1.0+API+Rebuild+Phase+1+-) 同步）
- **与需求强相关规则摘要**：
  - 发放：`clientOrderId`（无会员 / 第三方订单）与 `memberId`（已有会员）**二选一**；**未传 `memberId` 时 `clientOrderId` 必传**；同一 `clientOrderId` 不可重复发放（`500.031.002`）
  - 单条查询：支持 `voucherCode`、`clientOrderId`（发放时曾传入）；**不支持**按 `clientUserId` 查询
  - 列表：需覆盖 `categoryType`（SL / FT / DG / LS）、`status`、`validTo`；会员不存在 `301.010.002`
  - 状态：正常 <-> 冻结；正常或冻结 -> 作废；非法变更 `500.031.004`
  - 编辑：`500.031.003` / `500.031.005`（含总额不一致、不支持改 `usageAllocation`）
  - 二维码：SL / FT；`duration` 默认 60s；失败 `500.031.006`；需求返回名为 **`validUntil`**（若 OpenAPI 为 `vaildUntil` 则以实际响应字段断言）
