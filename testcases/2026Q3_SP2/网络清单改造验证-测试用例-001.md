## 项目资源清单对账（ResourcesInventory）

### GET_v2_resources

#### tc-p1: 资源列表与RedisExcel交集对账且基线Canary字段一致

- pc: 已准备新旧Redis缓存JSON（可同文件）；单一价配置Excel仅1个Sheet，含「网点编码NetworkCode」列；当前Program合法Bearer；可分别请求基线与`x-version=canary`。
- 从Redis JSON只取`hasLgNetworkData===true`的记录，按`networkCode`去重，对比新旧两侧数量与集合
  - 能打印两边数量、仅旧有、仅新有；去重规则生效，不含`hasLgNetworkData!==true`的编码
- 读取Excel「网点编码NetworkCode」，去空去重后与Step1求交得到Final
  - Final=Step1∩Excel；能打印最终数量与编码列表
- 调用`GET /v2/resources?pageSize=100&module={module}`（默认`module=1`，可按品类参数化），用`data.pagination.totalNumber`与列表项`resourceId`（来自`transportHubResources`/`lifestyleResources`）与Final比较
  - 列表总数与resourceId集合与Final一致
- 对Step3每个resourceId取列表项，并调用`GET /v2/resources/{resourceId}`；canary请求带`x-version=canary`，对字段全集深比对
  - 基线与canary不一致时打印resourceId、list/detail、字段路径、两边值；一致则无差异输出
- rc: 对账流水线见`tools/data-check/CompareRedisExcelResourcesPipeline.py`；忽略字段以流水线约定为准（如`$.lastUpdatedTime`）。
- tag: Redis,Excel,Canary,清单对账

### 批量获取与资源列表数量（BatchVsList）

#### tc-p1: 批量获取租户资源等于网络清单且资源列表等于网络清单与ES交集

- pc: 同一Program/项目可取到网络清单（`hasLgNetworkData===true`去重集合）、ES已插入资源集合；批量接口与`GET /v2/resources`可用。
- 调用批量获取租户资源接口（`GET /v2/projects/{projectId}/resources`或`POST /v2/programs/resources/batch`，以Apifox契约为准）

- 调用`GET /v2/resources`（相同module与筛选口径）
  - 返回的resourceId集合等于「网络清单∩ES已插入资源」；不得把仅在网络清单、未入ES的资源返回在列表中
- rc: 两接口数量允许不一致，差异应能用「未入ES」解释。
- tag: 批量接口,ES交集

## 目标语种与Fallback（LanguageFallback）

### GET_v1_resources_{resourceId}与GET_v2_resources_{resourceId}

#### tc-p1: 资源有目标语言翻译时按请求语种展示且不回退

| fallbackAllowed | 预期 |
| --- | --- |
| false | 展示对应语种信息，不回退 |
| true | 展示对应语种信息，不回退 |

- pc: 资源在清单内；Boss已维护目标语种翻译（如`zh-CN`）；v1与v2详情均可调。
- 分别以`fallbackAllowed=false`和`true`调用`GET /v1/resources/{resourceId}?language={目标语种}`与`GET /v2/resources/{resourceId}?language={目标语种}`
  - 四种组合均HTTP成功且`code=0`，文案为请求语种，不回退英文
- tag: 语种,fallbackAllowed

#### tc-p2: 资源没有目标语言翻译时按fallbackAllowed分支

| fallbackAllowed | 预期 |
| --- | --- |
| false | 报错并弹出合理提示（常见500.020.015或环境等价） |
| true | 用兜底语种英文展示 |

- pc: 资源在清单内；Boss仅有英文、无目标语种翻译；v1与v2详情均可调。
- 分别以`fallbackAllowed=false`和`true`调用`GET /v1/resources/{resourceId}?language={无翻译语种}`与`GET /v2/resources/{resourceId}?language={无翻译语种}`
  - 响应符合上表；`true`时返回英文兜底详情且`code=0`，`false`时不返回目标语种详情体
- tag: 语种,fallbackAllowed
