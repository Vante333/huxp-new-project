## 多等级 Tier 权益映射

### Tier 映射关系建立

#### 正向场景验证

- tc-P1-TMAP-001：Program A 各 Tier 的权益组合正确映射到 Program B 对应 Tier 的同类型组合
  - tc-P1: Program A 的 Tier1 充值/大客户持卡人/大客户携伴/大客户共享 → 映射到 Program B 的 Tier1 对应类型
  - tc-P1: Program A 的 Tier2 充值/大客户持卡人/大客户携伴/大客户共享 → 映射到 Program B 的 Tier2 对应类型
  - tc-P1: 映射关系按 Tier 编号一一对应
- tc-P2-TMAP-002：多 Tier 场景下各 Tier 独立映射，但迁移执行为原子操作
  - tc-P2: 每个 Tier 的权益映射规则独立判定
  - tc-P2: 不存在跨 Tier 的权益混合映射
  - tc-P2: 所有 Tier 映射成功后才执行迁移，任一失败则整体不迁移

#### Tier 整体迁移规则验证

- tc-P1-TMAP-003：同一 Tier 内所有权益类型都存在对应模板时，该 Tier 整体迁移成功
  - tc-P1: Tier1 的持卡人/携伴/共享/买点均存在模板 → Tier1 整体迁移成功
  - tc-P1: 迁移后目标 Program 的 Tier1 各类型权益数据正确
- tc-P1-TMAP-004：同一 Tier 内任一权益类型不存在对应模板，该 Tier 整体迁移失败
  - tc-P1: Tier2 携伴/共享不存在模板，即使持卡人/买点有模板 → Tier2 整体迁移失败
  - tc-P1: Tier2 的所有权益均不迁移（包括有模板的持卡人和买点）
- tc-P1-TMAP-005：多 Tier 迁移为原子操作，任一 Tier 迁移失败则整体失败
  - tc-P1: Tier1 模板匹配成功，Tier2 模板匹配失败
  - tc-P1: 整体迁移失败，Tier1 不执行迁移
  - tc-P1: 所有 Tier 权益数据均保持原状态不变
  - **请求参数**:
    ```json
    {
      "membershipId": "{{含多Tier权益的membershipId}}",
      "programId": "{{programId}}",
      "targetProgramId": "{{Tier2无模板的targetProgramId}}",
      "entitlementOptions": { "strategy": 3 },
      "validityOptions": { "strategy": 1 }
    }
    ```
  - **预期响应**:
    ```json
    {
      "code": -1,
      "msg": "Entitlement template not found for target program.",
      "errCode": "500.030.xxx"
    }
    ```
- tc-P1-TMAP-005-2：所有 Tier 均迁移成功时，整体迁移成功
  - tc-P1: Tier1 模板匹配成功且迁移成功
  - tc-P1: Tier2 模板匹配成功且迁移成功
  - tc-P1: 所有 Tier 权益数据正确迁移到目标 Program

#### 边界值验证

- tc-P3-TMAP-006：仅有单个 Tier 权益时的映射处理
  - tc-P3: 仅 Tier1 有权益时，只执行 Tier1 的映射和迁移
  - tc-P3: 不因缺少其他 Tier 而报错
- tc-P3-TMAP-007：Program A/B 权益组合数量不对等时的处理
  - tc-P3: Program A 有 3 个 Tier，Program B 仅有 2 个 Tier
  - tc-P3: 多余的 Tier 按无模板处理

#### 异常场景验证

- tc-P1-TMAP-008：Program A 存在某 Tier 但 Program B 无该 Tier 配置时，整体迁移失败
  - tc-P1: 该 Tier 因无对应模板导致整体迁移失败
  - tc-P1: 所有 Tier（包括有模板的）均不执行迁移
  - tc-P1: 权益数据保持原状态不变
  - **请求参数**:
    ```json
    {
      "membershipId": "{{含3个Tier权益的membershipId}}",
      "programId": "{{3Tier_programId}}",
      "targetProgramId": "{{仅2Tier的targetProgramId}}",
      "entitlementOptions": { "strategy": 3 },
      "validityOptions": { "strategy": 1 }
    }
    ```
  - **预期响应**:
    ```json
    {
      "code": -1,
      "msg": "Entitlement template not found for target program.",
      "errCode": "500.030.xxx"
    }
    ```
- tc-P1-TMAP-009：任一 Tier 迁移失败时，所有 Tier 迁移均回滚
  - tc-P1: Tier1 迁移成功后，Tier2 迁移失败
  - tc-P1: Tier1 已执行的迁移操作回滚
  - tc-P1: 所有权益数据恢复到迁移前状态
- tc-P1-TMAP-010：SWAP 组迁移失败时，整体迁移失败（包括所有 Tier）
  - tc-P1: SWAP 组与 Tier 级别为整体原子操作
  - tc-P1: SWAP 组失败导致所有 Tier 迁移回滚
  - tc-P1: 所有权益数据保持原状态不变

#### 数据状态验证

- tc-P1-TMAP-011：迁移后各 Tier 权益数据在数据库中的持久化正确性
  - tc-P1: 所有 Tier 均迁移成功时，所有权益数据已持久化
  - tc-P1: 任一 Tier 迁移失败时，所有 Tier 权益数据均未写入目标 Program
  - tc-P1: 数据库状态与迁移前一致（原子性保证）
